# Telegram Customer Support Bot

Telegram-бот для первичной поддержки клиентов, FAQ и сбора заявок.

## Возможности

- /start — запуск бота
- Раздел «Услуги»
- Раздел «Цены»
- Раздел «FAQ»
- Раздел «Контакты»
- Форма заявки: имя, контакт и описание задачи
- Сохранение заявок в SQLite
- Уведомление администратора о новой заявке
- /cancel — отмена заполнения заявки
- Повторное использование формы после отмены
- Постоянное отображение главного меню

## Технологии

- Python 3.10+
- python-telegram-bot (v22)
- Telegram Bot API
- SQLite
- python-dotenv

## Настройка

Создайте файл `.env` на основе шаблона `.env.example`:

BOT_TOKEN=your_bot_token_here
ADMIN_CHAT_ID=
DB_PATH=bot.db

- `BOT_TOKEN` — токен Telegram-бота. Получить его можно у `@BotFather`:
  отправьте команду `/newbot`, следуйте подсказкам и скопируйте выданный токен.
- `ADMIN_CHAT_ID` — Telegram ID администратора, которому приходят уведомления о
  новых заявках. Если параметр не указан (пусто), заявки сохраняются в SQLite
  без уведомления администратора.
- `DB_PATH` — путь к файлу базы данных SQLite. По умолчанию `bot.db`.

## Установка

Создайте и активируйте виртуальное окружение, затем установите зависимости:

python -m venv .venv

Linux / macOS:
source .venv/bin/activate

Windows (PowerShell):
.venv\Scripts\Activate.ps1

pip install -r requirements.txt

## Запуск

После активации окружения:

python bot.py

или одной командой (окружение и зависимости установятся автоматически):

./run.sh

## Хранение заявок

Заявки сохраняются локально в SQLite (`bot.db`).

Для каждой заявки записываются:
- ID
- имя
- контакт
- описание задачи
- дата создания

## Ограничения

- Бот работает в режиме long polling и требует постоянного запущенного процесса.
- Заявки хранятся локально в SQLite — без внешней БД и без синхронизации между
  машинами.
- `ADMIN_CHAT_ID` опционален: без него уведомления не отправляются.
- Нет панели администратора и экспорта заявок в CRM/таблицы.
- `run.sh` рассчитан на Linux/macOS/WSL. На Windows используйте `python bot.py`
  либо Git Bash / WSL.

## Безопасность

Токен Telegram-бота не должен попадать в исходный код, README или публичный репозиторий.
